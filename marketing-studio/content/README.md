# Room Zero Draft Content

Everything in this directory is a draft. No file is approved or scheduled merely because it validates or renders.

## Workflow states

1. `concept`: an unproduced original idea.
2. `draft`: structured copy or a render candidate.
3. Trust review: `trust-gate` returns blocked, changes required, or draft-ready for human decision.
4. Human approval: applies only to the exact reviewed version.
5. Publication: performed manually outside this repository and outside every agent workflow.

Scripts are the source of truth for visible copy and caption timing. Run `pnpm studio:validate` before rendering and `pnpm studio:captions` to regenerate SRT, VTT, and plain-text transcripts. Calendar entries are proposals, not scheduler instructions. Every `hypothesis` in `ideas/launch-ideas.json` is an untested creative rationale, never a performance finding.

Use only public or fictional material. Never place member posts, private analytics, account credentials, or platform tokens in this directory.
